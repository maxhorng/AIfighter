# AIfighter / NEON CLASH — Phaser 4 格鬥原型

以 Phaser 4 製作的單人 2D 對戰格鬥原型。角色是具立體光影的 2.5D 火柴人，使用球形關節、圓柱光影與地面陰影繪製；場景與角色都不需另下載圖片素材。

角色姿勢集中在 `stickman.js`：頭與頸部跟隨肩膀，手腳由共用關節端點及固定骨長計算。下蹲、蹲防、蹲攻、起身均重新計算完整骨架，避免各部位分別移動造成脫節。

## 開始遊玩

直接用瀏覽器開啟 `index.html`，或到 [GitHub Pages 遊戲頁](https://maxhorng.github.io/AIfighter/) 遊玩。Phaser 4 引擎已包含在 `vendor/phaser-4.0.0.js`，下載本專案即可獨立執行。

## 操作

- `A / D` 或方向鍵：左右移動；朝對手反方向移動時會減速並自動防禦
- `W`：原地跳躍；`W + A / D`：後跳／前跳（方向依對手位置判斷），起跳後直到落地都鎖定水平方向
- `S`：蹲下；`S + J / K / L`：蹲下輕／中／重攻擊
- 空中按 `J / K / L`：跳躍輕／中／重攻擊；跳躍中攻擊會保留跳躍方向，跳 `K` 可越過對手打背
- `Shift + A / D`：向所按方向短暫衝刺，每次消耗 15 氣量；Shift 單獨按不會防禦
- 後方向：後走站防；`S` 或 `S + 後方向`：原地蹲防
- `J / K / L`：輕／中／重攻擊
- `U`：氣功波（消耗氣量）
- `I`：升龍拳（消耗氣量）
- `236 / 214 + J / K / L`：下前／下後擊飛技，可接浮空追擊
- `623 + J / K / L`：對空昇龍；搓招依角色面向鏡像，手動搓招不消耗氣量
- `R`：重新開始

普通攻擊接觸對手後可以依輕→中→重取消，也可取消到搓招必殺；擊飛必殺命中後可以再接普通攻擊。連段數依對手是否仍在受擊硬直或浮空中累計。防禦時承受約一成傷害，攻擊命中可累積氣量。

蹲下 J/K/L 是下段，會打穿站立防禦；按住 S 即可蹲防。空中與衝刺期間不能防禦，跳 K 越過對手後可打背。

衝刺只限地面可操作時使用，持續 10F（約 0.17 秒），速度 660px/s，距離約 110px，起動後方向固定。兩次衝刺起動至少相隔 18F；按住 Shift+A/D 不會連續觸發，放開 Shift 或方向後重新按下即可再次衝刺。衝刺中不能攻擊，受擊會中斷；氣量不足時無法衝刺，命中攻擊可累積氣量。

### 攻擊幀數（60 FPS）

| 站立攻擊 | 出招 | 判定 | 收招 | 合計 | On block | On hit |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 輕攻擊 `J` | 6F | 6F | 11F | 23F | +3F | +12F |
| 中攻擊 `K` | 11F | 7F | 16F | 34F | -8F | +11F，雙方各退開 14px |
| 重攻擊 `L` | 19F | 9F | 27F | 55F | -12F | 擊飛，可追擊 |

出招是攻擊前搖，判定是可以打中對手的時間，收招是動作結束前的硬直時間；重攻擊威力較高，但前搖與收招都更長。

幀差是攻擊者與防禦者恢復操作的時間差：+3F 表示攻擊者早 3 幀恢復，-8F 表示對手早 8 幀恢復。地面 J/K 命中及 J/K/L 格擋依這個時間差設定硬直，晚命中也保持指定幀差。取消招式會以新招式的收招時間為準；浮空受擊則依落地時機恢復。

### 搓招與追擊

每次搓招在 0.6 秒內完成，最後方向後 0.16 秒內按 J/K/L；同時按兩個方向形成斜方向。

| 招式 | 面向右方 | 面向左方 | 效果 |
| --- | --- | --- | --- |
| 236 下前 | S → S+D → D + 攻擊 | S → S+A → A + 攻擊 | 昇掌，擊飛並追擊 |
| 214 下後 | S → S+A → A + 攻擊 | S → S+D → D + 攻擊 | 反向挑擊，擊飛並追擊 |
| 623 昇龍 | D → S → S+D + 攻擊 | A → S → S+A + 攻擊 | 對空昇龍，擊飛敵人 |

接近對手後可嘗試 `J → K → 236+J → J → K`；需在前一招接觸對手後輸入下一招。也可以 `L → 214+J` 擊飛後再用普通攻擊追打。浮空敵人會依重力落地，攻擊需要同時在水平距離與高度範圍內才能連上。

### 規則檢查

`node combat-check.cjs` 檢查幀差、左右鏡像搓招、下段防禦、雙方推開、擊飛落地、空中追擊、跳躍方向鎖定，以及衝刺耗能、冷卻、方向鎖定與受擊中斷。這些檢查不包含瀏覽器畫面。
